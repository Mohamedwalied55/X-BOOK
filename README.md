# XBOOK — Full Store + Control Room

نسخة XBOOK الكاملة، مصممة بنفس روح وتصميم المرجع المتفق عليه: أخضر داكن + Mint + أبيض، واجهة كتب شبيهة بمتاجر الكتب التعليمية، مع هوية Classified / Secret Agent.

## الموجود في النسخة
- متجر متجاوب للموبايل والكمبيوتر.
- بحث مباشر عن الكتاب/المدرس/المادة.
- فلاتر الصف والمادة والمدرس والمتاح فقط.
- صفحات/أقسام أولى ثانوي، ثانية ثانوي، ثالثة ثانوي، وكل الكتب.
- بطاقات كتب + أسعار + مدرس + إضافة للسلة.
- سلة مشتريات بكميات وإجمالي.
- طلب بدون دفع إلكتروني.
- حفظ الطلبات في PostgreSQL.
- Control Room حقيقية محمية بتسجيل دخول.
- إضافة/تعديل/حذف الكتب ورفع الأغلفة.
- إضافة/تعديل/حذف المدرسين ورفع الصور.
- متابعة الطلبات وتغيير الحالة وحذف الطلب.
- تعديل Hero والعنوان والوصف وAbout ورقمي WhatsApp.
- رفع/استبدال صورة Hero من Control Room.
- Dark Mode.
- صور الأغلفة والمدرسين وHero محفوظة في PostgreSQL بدون خدمة صور مدفوعة.

## Railway
1. اربط خدمة Node بخدمة PostgreSQL حتى يتوفر `DATABASE_URL`.
2. ضع المتغيرات:
   - `DATABASE_URL` (Railway يوفره من PostgreSQL)
   - `JWT_SECRET` قيمة عشوائية قوية
   - `ADMIN_EMAIL` بريد دخول Control Room
   - `ADMIN_PASSWORD` كلمة مرور Control Room
3. Start command: `npm start`
4. افتح `/` للموقع و`/admin` للإدارة.
